# サイト組み立てチェックリスト（Build Manifest）

> **これは「何を組み立てるか」の総ざらいリスト。** 抜け漏れを出さないための持ち物表。
> 「どう運用して壊さないか（危険度・爆発半径・14日観察・デプロイ規律）」は姉妹ドキュメント
> **`docs/site-playbook.md`** を正典とする。この2つはセットで使う。
>
> 記号: **【必須】** = 無いと公開できない／事故る ／ **【推奨】** = 通常入れる ／ **【任意】** = 要件次第
> ⚠️ = 忘れやすい・後回しにして事故りやすい項目

---

## フェーズ A. 企画・情報設計（コードを書く前に決める）

- [ ] **【必須】サイトの目的**（何で問い合わせ／受注を取るのか）を1文で言語化
- [ ] **【必須】ターゲット**（誰が・どの国・どの言語・どんな検索意図で来るか）
- [ ] **【必須】提供サービス／商品の一覧**と、それぞれの料金・納期
- [ ] **【必須】対応言語**（単一 or 多言語。多言語なら §D の hreflang が必須になる）
- [ ] **【必須】サイトマップ（ページ構成）**を先に紙で描く ⚠️ ここを飛ばすと後でURL設計が破綻する
- [ ] **【必須】URL設計**（`/service-name/` の付け方・trailing slash 有無・言語プレフィックス `/ja/` `/en/`）
      → 一度決めたら**変えない**（playbook Lv1）。ここが最重要の一発勝負
- [ ] **【推奨】キーワード調査**（各ページで狙う検索クエリ・取引意図か情報意図か）
- [ ] **【推奨】競合サイトの構成**を3つ見て、必要ページの抜けを確認

---

## フェーズ B. デザイン・ブランド資産

- [ ] **【必須】ロゴ**（SVG または高解像度PNG）
- [ ] **【必須】favicon** ⚠️ 忘れがち（`.ico` ＋ `apple-touch-icon` ＋ 各サイズ）
- [ ] **【必須】OGP画像**（SNS/LLMシェア時のサムネ・1200×630）⚠️ 無いとシェアが貧相になる
- [ ] **【必須】カラーパレット・フォント**（本文/見出し/アクセント。Webフォントは CWV 注意）
- [ ] **【必須】レスポンシブ方針**（PC/スマホ両方で崩れないこと。スマホ実機確認）
- [ ] **【推奨】UIコンポーネントの共通化方針**（Header/Footer/Hero/CTA/カード）
      → ただし共通コンポーネントは全ページ波及（playbook §3）。公開後は連打しない
- [ ] **【任意】ダークモード対応**
- [ ] **【推奨】アクセシビリティ**（十分なコントラスト・キーボード操作・フォーカス表示）

---

## フェーズ C. 技術基盤・ホスティング

- [ ] **【必須】フレームワーク選定**（Vite+React 等）＋**静的プリレンダー（SSG）** ⚠️ SEO/LLMOの土台
- [ ] **【必須】メタ管理を単一ソース化**（title/description の二重管理を作らない。playbook §1）
- [ ] **【必須】ルーティング**（URL設計どおりに）＋ **404ページ** ⚠️ 忘れがち
- [ ] **【必須】ビルドコマンド一式**（lint → build → prerender → sitemap生成）
- [ ] **【必須】ホスティング**（例: Cloudflare Pages）＋ **本番ドメイン取得**
- [ ] **【必須】DNS設定 ＋ SSL/HTTPS** ⚠️ HTTPS必須（無いとSEO・信頼で不利）
- [ ] **【必須】`_redirects`（301リダイレクト・trailing slash 正規化）**
- [ ] **【推奨】プレビュー環境**（PRごとの自動デプロイ）
- [ ] **【推奨】CI**（ビルド失敗・SEO lint を公開前に止めるゲート）
- [ ] **【推奨】環境変数・シークレット管理**（APIキー等をコミットしない）

---

## フェーズ D. SEO / LLMO ベースライン（構造・公開前に1回）

> ここは playbook Lv1〜2。**公開前に正しく1回入れて、以後凍結**する領域。

- [ ] **【必須】各ページ title / meta description**（検索意図に沿う・重複させない）
- [ ] **【必須】canonical**（self-canonical を全ページに）
- [ ] **【必須】OGP / Twitter Card メタ**（title/description/image/url）⚠️
- [ ] **【必須】sitemap.xml**（自動生成・全URL）
- [ ] **【必須】robots.txt**（クローラー許可 ＋ **AIクローラー明示Allow** ＋ `Sitemap:` 行）
- [ ] **【必須・多言語のみ】hreflang**（HTML head ＋ sitemap 両方・`x-default` 付き・相互参照）
- [ ] **【推奨】構造化データ JSON-LD**（Organization / Service / FAQ / HowTo / BreadcrumbList）
- [ ] **【推奨】`/llms.txt`**（要約・料金表・ページ一覧。LLMの引用ソース）
- [ ] **【推奨】`/llms-full.txt`**（詳細版・任意）
- [ ] **【必須】H1 は各ページ1つ**・見出し階層（H1→H2→H3）が正しい
- [ ] **【必須】画像の alt 属性**（全画像）⚠️
- [ ] **【推奨】パンくずリスト**（ユーザー導線＋BreadcrumbList構造化データ）

## フェーズ E. コンテンツ（各ページ本文）

- [ ] **【必須】トップページ**（何のサイトか3秒で分かる・主要サービスへの導線）
- [ ] **【必須】サービス／商品ページ**（各サービス1ページ・料金・納期・手順）
- [ ] **【必須】料金ページ or 各ページ内の料金ブロック**（プレーンに明記。LLMOにも効く）
- [ ] **【必須】会社概要 / 運営者情報**（YMYL領域では信頼のため特に重要）
- [ ] **【必須】お問い合わせページ**（§F フォーム）
- [ ] **【推奨】FAQページ**（+ FAQ構造化データ）
- [ ] **【推奨】導入事例・お客様の声**（信頼要素）
- [ ] **【推奨】ブログ／お役立ち記事**（沈んだKWを拾う継続コンテンツの受け皿）
- [ ] **【必須】内部リンク**（孤立ページを作らない・重要ページへ導線を集める）

---

## フェーズ F. コンバージョン導線

- [ ] **【必須】CTA**（主要ページに明確な行動喚起ボタン・追従CTA等）
- [ ] **【必須】問い合わせフォーム**
  - [ ] 項目は最小限
  - [ ] **流入元（referral_source）項目** ⚠️ これが無いとチャネル分析が永遠にできない
  - [ ] **送信のバックエンド**（メール送信 or DB保存 or 両方）
  - [ ] **スパム対策**（reCAPTCHA / honeypot / レート制限）⚠️ 忘れると業者スパムで埋まる
  - [ ] **送信後の完了ページ／サンクスページ** ⚠️（+ 計測のコンバージョン地点）
  - [ ] バリデーション・エラーメッセージ（何が悪くどう直すか）
- [ ] **【推奨】信頼要素をCTA近くに**（決済バッジ・実績・返金条件・対応言語）
- [ ] **【任意】オンライン決済**（ホスト型 Checkout・カード情報を自前で持たない・結果ページは noindex）
- [ ] **【任意】顧客DB / CRM**（フォーム→DB→管理画面。PIIは noindex＋認証＋暗号化）
- [ ] **【推奨】電話／チャット／LINE等の代替導線**

---

## フェーズ G. 法務・コンプライアンス ⚠️ 最も忘れやすい

- [ ] **【必須】プライバシーポリシー**（個人情報の取得・利用・第三者提供。フォームがあれば必須）
- [ ] **【推奨】利用規約**
- [ ] **【必須・日本で決済するなら】特定商取引法に基づく表記** ⚠️ 決済を入れるなら法的に必須
- [ ] **【必須・EU等対象なら】Cookie同意 / GDPR対応**（計測タグを入れるなら特に）
- [ ] **【推奨】会社の実在情報**（住所・連絡先。YMYL/E-E-A-Tの信頼シグナル）
- [ ] **【任意】返金・キャンセルポリシー**（決済がある場合は明示）

## フェーズ H. 計測・分析

- [ ] **【必須】Google Search Console 登録**（ドメイン所有権確認・sitemap送信）
- [ ] **【推奨】GA4 等のアクセス解析**（タグは `async`/`defer`・CWVを悪化させない）
- [ ] **【推奨】コンバージョン計測**（フォーム送信・電話クリック・決済完了をイベント化）
- [ ] **【任意】ヒートマップ／行動分析**（Clarity等）
- [ ] **【推奨】GSCとGA4の役割を理解して両方見る**（検索での見え方 vs サイト内行動）

## フェーズ I. 品質保証（公開前チェック）⚠️ ここを飛ばさない

- [ ] **【必須】全ページ表示確認**（PC・スマホ実機。レイアウト崩れ・折り返し・重なり）
- [ ] **【必須】リンク切れチェック**（内部リンク・外部リンク・ナビ）
- [ ] **【必須】フォーム送信テスト**（実際に送って、届く／保存される／完了ページに飛ぶ）
- [ ] **【必須】表示速度 / Core Web Vitals**（LCP/CLS/INP を Lighthouse で確認）
- [ ] **【必須・多言語】言語切替**（各言語版が正しく表示・hreflang整合）
- [ ] **【必須】クロスブラウザ**（Chrome/Safari/Firefox・iOS Safari）
- [ ] **【必須】メタ/OGP のプレビュー確認**（SNSシェア・検索スニペット）
- [ ] **【推奨】アクセシビリティ**（alt・コントラスト・キーボード操作）
- [ ] **【必須】robots.txt が本番で正しい**（公開時にサイト全体を Disallow したままにしない）⚠️

## フェーズ J. 公開・公開直後

- [ ] **【必須】本番デプロイ**
- [ ] **【必須】旧サイトがある場合、旧URL→新URLの301** が全て効いているか実機確認
- [ ] **【必須】robots.txt / sitemap.xml が本番URLで到達可能**
- [ ] **【必須】GSCでsitemap送信 ＋ 主要ページのインデックス登録リクエスト**
- [ ] **【推奨】主要ページの検索スニペット・OGPを実機で最終確認**
- [ ] **【必須】ここから playbook の運用モードへ移行**
      → 構造は凍結・コンテンツは日次・大変更は14日観察・デプロイ前チェックカード

## 最頻の抜け漏れ TOP 10（これだけでも先に潰す）

1. ⚠️ **特定商取引法の表記**（日本で決済するのに無い＝違法状態）
2. ⚠️ **プライバシーポリシー**（フォームがあるのに無い）
3. ⚠️ **404ページ**（未設定でデフォルトの素っ気ない画面）
4. ⚠️ **OGP画像**（SNS/LLMシェアが貧相）
5. ⚠️ **favicon**（タブがのっぺらぼう）
6. ⚠️ **フォームのスパム対策**（業者スパムで受信箱が埋まる）
7. ⚠️ **サンクス／完了ページ**（コンバージョン計測地点が無い）
8. ⚠️ **referral_source（流入元）項目**（どのチャネルが効いてるか分からなくなる）
9. ⚠️ **画像の alt**（SEO・アクセシビリティ両方の抜け）
10. ⚠️ **公開時に robots.txt を全 Disallow のまま**（検索に一切載らない大事故）
