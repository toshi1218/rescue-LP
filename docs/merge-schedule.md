## 注意事項

- **main merge は 2026-07-15 まで禁止**（CLAUDE.md）。解除はユーザーが「main merge」と入力した時のみ
- 🟢 は本来「コンテンツ自由・日次OK」だが、リマインドを機能させるため約3日間隔で配置（前倒しで一気にやらない）

- 安全PRも古いブランチは **マージ前に origin/main へリベースし、CLAUDE.md 競合を解消**すること
- **受注を上げる最速手は SEO ではなくコンバージョン改善**（CTA・価格・納期・信頼要素）。構造非依存・即効・リスクゼロなので、上記スケジュールと無関係にいつでも実施可
