# ToB戦略メモ — 行政書士向けPH書類取得代行

作成日: 2026-06-29

---

## 背景・目的

フィリピン人帰化申請・国際結婚手続きを扱う行政書士事務所の一部が、PSA証明書取得〜DFAアポスティーユ〜日本発送までを「代行サービス」として顧客に提供している。貴社IGRS事業にとっての**ToB機会**（行政書士への裏方提供）と**直接競合**を整理したもの。

## ② 貴社の勝ち筋

1. **Barros-Keiの弱点=価格非提示・高単価** → 貴社は**定額パッケージを提示するだけ**で優位
2. **OFFICE O.Iの弱点=現地拠点が見えない** → 貴社の**セブ拠点による「エラー訂正の速さ」**が差別化軸
   - PSAは綴り・日付ミスが多く、訂正で2〜3週間飛ぶのが業界の痛点
   - 「現地で即訂正」と言えるのは現地拠点を持つ事業者だけ
3. **ToB卸値の目安**: 顧客向け相場 ¥22,000〜¥30,000 に対し、**¥12,000〜¥18,000/通**あたりが交渉のスイートスポット
   - 行政書士側に ¥5,000〜¥10,000 程度の粗利が残る構造

## ④ アプローチ戦略

### 優先順位
1. **第一綜合・エールZEALを最優先**: フィリピン案件の実績がありながら「本人取得」前提 = 現地オペを外注したい動機が最も強い
2. ⬜要確認の事務所は電話/問い合わせで「PSA書類の取得は御所が代行されますか？」と確認 → 「いいえ」なら即提案

### 提案フレーム
「御所は日本側手続き（帰化・入管・法務局・翻訳）に集中、PH現地のPSA取得〜訂正〜DFA〜発送は弊社が裏方（ホワイトラベル）で巻き取ります」

### 刺すポイント（価格ではなく納期・確実性）
- Barros-Keiの「全部見積り・納期不明」に対し → **定額・納期明示**
- 本人DIYの「6〜8週間」に対し → **セブ拠点による短納期（目標◯週間）**
- PSA訂正リスクに対し → **現地で即対応・追加費用なし**

### 継続取引化
「帰化は一度きり」だが、**NBI・LTO（外免切替）・CENOMAR等のrecurring書類**を束ねると継続受注に転換できる。帰化→外免切替→子供のNBI、と一家族で複数回の取引になりうる。

### ④-3 ターゲット適格性の判断（重要・全部が等しく適格ではない）

「フィリピン案件を扱う＝適格」ではない。以下4軸で選別する。

| 適格性の軸 | 内容 |
|---|---|
| ① 取得の「痛み」が実在するか | 申請者本人がPH書類を自力取得できない案件か。**帰化＞国際結婚** |
| ② 案件ボリューム | 中規模が理想。大手は内製/既存提携、零細は数が出ない |
| ③ 取得を誰がやる文化か | 顧客丸投げ/外注派＝適格。内製派＝対象外 |
| ④ 再販を受け入れるか | 粗利を乗せて売る文化か、無償で紹介して終わる文化か |

#### セグメント別 適格度

**A. 帰化フォーカス事務所 → 適格度【高】（本命セグメント）**
- 理由: 帰化申請者は**在日歴が長く、PH側に頼れる家族が疎遠/不在**のケースが多い。本国書類（出生・婚姻・死亡・CENOMAR）の取得が実際の難所になり、事務所も「ここだけ巻き取ってほしい」ニーズが出やすい。家族の連鎖帰化で**recurring性**もある
- 該当: 第一綜合 / エールZEAL / 三品美咲 / まつとう / 日浦 / サポートタワーズ / ごとう / kika-help / やなぎグループ / partnerhd / 浜松国際 / 藤井 / 帰化@JAPAN

**B. 国際結婚・配偶者ビザフォーカス事務所 → 適格度【中〜低】**
- 理由: フィリピン人配偶者は比較的若く**PH側に家族がいることが多い**ため、出生証明書/CENOMAR/LCCMは**本人・家族が現地で取得する**のが通常。事務所は書類取得に関与しない＝**取得代行の出番が構造的に小さい**
- 例外的に需要が出るケース: 再婚（離婚・死亡証明が必要）/ 配偶者が長く在日で現地に頼れる人がいない / 急ぎ / 訂正が発生
- 該当: 清水真一 / さとうなおき / kekkonvisa.tokyo / ビザ専門行政書士 / つばくろ / JOY / コモンズ / くまがい / touch / アクティス / 広島 / やまなし
- → **メール文面は「再婚・訂正・現地に頼れない案件のときだけでも」と限定して刺すと反応が取りやすい**

**C. 全国大手 → 適格度【条件付き】**
- さむらい / 第一綜合 / やなぎ / コモンズ。ボリュームはあるが**内製 or 既存提携先を持つ可能性が高い**。刺されば大きいが決裁が遠い
- 攻め方: フルパッケージではなく「**繁忙期のオーバーフロー対応**」「**訂正案件だけ**」「**特急便だけ**」など部分提供で入り込む

#### 結論（適格性の最終判断）
- **本当に適格なのは「帰化に強い中規模事務所」**。ここが第一波。
- 国際結婚専業は**一段適格度が落ちる**（顧客が自分で取る構造のため）。送るなら限定フックで。
- 大手は**部分提供**で入る。最初からフルパッケージを売り込まない。
- 33件を一律に送るのは非効率。**A群（帰化）を最優先**に、B群は限定フック、C群は別アプローチ、と文面を分ける。

### コールド営業の進め方メモ
1. **送信順**: 🟩本命（第一綜合・エールZEAL）→ 中小規模の🟦候補 → 大手は最後（内製率が高い想定）
2. **連絡経路**: 多くは公開メールではなく**問い合わせフォーム**。フォーム経由はスパム判定されにくく、特定電子メール法の観点でも安全
3. **特定電子メール法（B2B営業メール）**: 業務上の営業は許容されるが、①送信者の氏名・住所明記 ②配信停止導線、は入れる。フォーム経由なら相手の受信導線内なので無難
4. **一斉送信しない**: 同一文面の大量送信は到達率・印象とも悪化。本命に手書き感のある個別文面を少数から
5. **フック**: 価格ではなく「現地セブ拠点による訂正の速さ・納期の確実性」。「御所は日本側手続きに集中、PH現地は弊社が裏方で」
