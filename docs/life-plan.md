## 🔴 Phase 1：勉強中の家計を立てる（最重要・いま未解決）

### 問題の正体：収入には2フェーズある。混ぜると詰む

| | Phase 1：**今〜免許取得まで** | Phase 2：**免許取得後** |
|---|---|---|
| 必要なもの | 家族を養う金（日本帰国で嫁さんのビジネスは消える） | 自由・旅・低ストレス |
| 手段 | **自分のスキルで稼ぐ（下記）** | 産業医・健診・精神科非常勤 |
| 状態 | 🔴 ここが本当の問題 | 🟢 原理的に解決済み |

→ **医師レーンは全部 Phase 2。勉強中の家計は1円も助けない。** 予備試験の勉強中に
家族を養う手段（Phase 1）を別に立てないと、金の不安で勉強が崩れる。これが核心。

### 緊急度：今もらってる15万は「相続前借り＝借金」

毎月の仕送り¥15万は、港五丁目の父の土地（将来相続予定）を**前借りしている実質借金**。
医者になるまで乗り続けられない。**だから最適化すべきは「優雅さ」ではなく「自分の金が
入るまでのスピード」**。月15〜20万を、まず自分の稼ぎで即金で立てる。
→ この緊急度ゆえ、**遅い行政書士フックは主役から外れる**（後述）。

### 収入の中心思想：外貨アービトラージ ＋ アイデンティティ分離

全部の話が収束した一文：
> **AI＋英語で言語の壁を消し、お金を持っている国（NY・北欧・カナダ・豪州）から
> 外貨で稼ぎ、安い日本（or 旅先）で、自分として暮らす。**

- **金のあるところで釣れ**：NYの医者は5分$300、鍼灸の先生は1時間$300を"狙う"。
  フィリピン人向けの薄利とは真逆。**稼ぐ通貨＝ドル/ユーロ、暮らす物価＝安い日本**
  の地理的アービトラージ。
- **🔑 アイデンティティ分離（判断軸）**：母（貝塚市の音楽教師）が紀の川を渡って
  ようやく"鎧を脱げた"話。**「役割で見られる場所」と「自分として暮らす場所」を分けたい**。
  → これは選択を裁く軸：**国内士業コミュニティに入る＝また役割で embed される＝
  この軸に反する**。**海外/オンラインの遠い客から稼ぐ＝暮らす地域は自分を役割で
  見ない＝軸に合う**。本人の最深の価値観が「海外・オンライン」を「国内士業」より上に置く。
- **人口減少の島国の小さい池でパイを奪い合わない。外に出て外貨を取る。**
- **医者は捨てない＝国内の"地面（floor）"**（安心感・体裁・数十年揺るがない最低保証）。
  **外貨リモート事業＝自由・成長・分離の層**。二階建て。どっちか、ではない。

### 診断：書類ビジネスの「失敗」を正確に

スキルの失敗ではない（多言語SEOサイトを現に作りきった）。原因は2つだけ：
1. **ターゲットが薄利**（フィリピン人向け1〜2万・薄利）。構造的に払える天井が低い市場。
2. **B2Bを"待ち"でやった**（9ヶ月でB2B問い合わせ実質ゼロ）。
   → 教訓：**B2BはSEOで待っても来ない。こっちから取りに行く（アウトバウンド）もの。**

→ 足りない唯一のスキルは「作る力」ではなく **「客を取る力（営業・アウトバウンド）」**。
嫁さんビジネスが潰れた時に何もできなかった根本原因も「自分の稼ぐエンジンがなかった」
こと。二の轍を踏まないために、**自分が所有する稼ぐエンジン**を持つ。

### 方針：同じスキルを"高単価B2B"に向け直す

- A（Web/LP/SEO/動線）か B（AI導入・自動化）かは**本物の分岐ではない**。
  混むのは「ジェネリック・情報・単発」の層。混まないのは
  **「特定業種に・実装代行で・継続課金」**の層。
- **差別化はニッチで決まる**。技術ではない。ニッチを決めれば A は入口、B＋保守は
  月額本命、で自然に混ざる。
- **月額顧問（リテイナー）が生命線**：一度取れば毎月入る＝営業負荷が小さい＝
  勉強と両立できる唯一の形。単発は永遠に客を取り続ける地獄。
- **🔑 地元無色ルール**：地元（和歌山市）＝医師の肩書き専用。サイドビジネスで
  変な色をつけない。地元クリニックのサイト制作で失敗すると医師の評判に傷がつく。
  → さらに本人の理想は**「地元でも国内でもなく、海外/オンラインの客」**（上の
  アイデンティティ分離より）。客は遠ければ遠いほど、暮らす自分と切り離せる。

### 具体設計：同じスキルを「海外・外貨」に向け、2速で走らせる

売るスキル（共通）：**Web/LP・問い合わせ動線・AI自動化・追客の仕組み化**。
武器：作った実績サイト（ポートフォリオ）＋英語＋AIネイティブ＋元医療者。

**⚠ 正直な速さの現実**：「お金持ちの欧米クライアントに高単価で直販」は理想だが、
**コールドで取りに行くと国内より遅い**（海外に温かい人脈がない・国境越しの信頼構築）。
緊急の15万即金をこれに賭けると詰む。だから2速に分ける：

**🚀 速い橋（ブリッジ）：今の15万を置き換える near-term 現金**

| 項目 | 中身 |
|------|------|
| どこで | **グローバルのフリーランス市場（Upwork 等）= すでにドルが流れてるプール** |
| 何を | Web/LP制作・AI自動化・スクレイピング/業務自動化など、欧米クライアント案件 |
| ポジショニング | 「AI-powered web/automation・多言語(英/日)・元ヘルスケア」 |
| 速さ | **数週間で最初のドル**が現実的。最初はレート低め→レビュー蓄積→単価ラチェットで上昇 |
| 満たすもの | 外貨・自分のスキル・所有エンジン・即金性。緊急度に唯一フィット |

**🏗 遅い本命（ビルド）：高単価ダイレクトを時間をかけて積む**

| 項目 | 中身 |
|------|------|
| 誰に | 金を持つ欧米の特定ニッチ（SMB・専門職・クリエイター等）へ直接 |

**国内の代替（優先度↓・保険）**：どうしても海外が立ち上がらない時のみ、
非地元の遠方クリニック（医師の信頼）や士業（行政書士フック）。ただし
**アイデンティティ分離の軸では国内・士業は本人の理想に反する**ため後回し。

### 行政書士フックの扱い（降格・保留）

緊急度（遅い）＋ アイデンティティ分離（国内コミュニティに embed される）の2点で、
**主役から外れた**。やるとしても「保険の国内チャネル」止まり。もし将来使うなら3注意：
1. **合格 ≠ 会に入れる**（登録に事務所＋入会金20万前後＋月会費。和歌山県行政書士会の額は要確認）。

3. **本物にする**（評判に敏感な小さい士業界。騙し版は逆効果。正直版が強い）。

## 医師免許の使い方：レーン選択

「医者」は一つの仕事ではなく、免許は**メニュー**。低WM負荷 × 高自由度の項目を選ぶ。

| 働き方 | WM負荷 | 場所・時間の自由 | 相性 |
|--------|--------|------------------|------|
| **嘱託産業医** | 低 | 高（1社 月1〜数回を複数掛け持ち） | ★本命。B2Bで一番お金を落とす |
| **健診・人間ドックバイト** | 極低 | 高（働く日を選ぶ・1日¥5〜10万・継続診療なし） | ★単発で稼げる。旅と両立 |
| ~~オンライン診療（自由診療）~~ | 低 | × 海外からは距離・在宅制限で実質不可 | 当面外す（国内拠点が要る） |
| **精神科・心療内科の外来 非常勤** | 中〜低 | 中 | ◎ 言語理解113が武器。PTで精神病院にいた時「こんな緩い所ない」と実感済み |
| **寝当直・施設当直**（救急当直は除く） | 低 | 中（夜だけ・¥3〜10万） | ◎ 忙しい救急当直は選ばない |
| 救急 / 外科 / 産婦人科 / 急性期病棟 | **高** | 低 | ❌ 避ける（WMの谷を最も深く突く） |

**結論**：クリニックを開く必要も、毎日同じ時間に出勤する必要もない。
フリーランス非常勤医として低WM・高自由メニューをつまみ食い ＝
「ある程度のお金 ＋ 場所と時間の自由 ＋ 低ストレス」＝ 旅する人生そのもの。

> ⚠ 「自分のクリニックを開く」は罠。毎日開けねばならず、非常勤医を雇って回るまで
> 何年もかかり、旅の人生が消える。**開業はしない。**
