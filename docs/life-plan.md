## 🔴 Phase 1：勉強中の家計を立てる（最重要・いま未解決）

### 問題の正体：収入には2フェーズある。混ぜると詰む

| | Phase 1：**今〜免許取得まで** | Phase 2：**免許取得後** |
|---|---|---|
| 必要なもの | 家族を養う金（日本帰国で嫁さんのビジネスは消える） | 自由・旅・低ストレス |
| 手段 | **自分のスキルで稼ぐ（下記）** | 産業医・健診・精神科非常勤 |
| 状態 | 🔴 ここが本当の問題 | 🟢 原理的に解決済み |

→ **医師レーンは全部 Phase 2。勉強中の家計は1円も助けない。** 予備試験の勉強中に
家族を養う手段（Phase 1）を別に立てないと、金の不安で勉強が崩れる。これが核心。

### 診断：書類ビジネスの「失敗」を正確に

スキルの失敗ではない（多言語SEOサイトを現に作りきった）。原因は2つだけ：
1. **ターゲットが薄利**（フィリピン人向け1〜2万・薄利）。構造的に払える天井が低い市場。
2. **B2Bを"待ち"でやった**（9ヶ月でB2B問い合わせ実質ゼロ）。
   → 教訓：**B2BはSEOで待っても来ない。こっちから取りに行く（アウトバウンド）もの。**

→ 足りない唯一のスキルは「作る力」ではなく **「客を取る力（営業・アウトバウンド）」**。
嫁さんビジネスが潰れた時に何もできなかった根本原因も「自分の稼ぐエンジンがなかった」
こと。二の轍を踏まないために、**自分が所有する稼ぐエンジン**を持つ。

### 方針：同じスキルを"高単価B2B"に向け直す

- A（Web/LP/SEO/動線）か B（AI導入・自動化）かは**本物の分岐ではない**。
  混むのは「ジェネリック・情報・単発」の層。混まないのは
  **「特定業種に・実装代行で・継続課金」**の層。
- **差別化はニッチで決まる**。技術ではない。ニッチを決めれば A は入口、B＋保守は
  月額本命、で自然に混ざる。
- **月額顧問（リテイナー）が生命線**：一度取れば毎月入る＝営業負荷が小さい＝
  勉強と両立できる唯一の形。単発は永遠に客を取り続ける地獄。
- **🔑 地元無色ルール**：地元（和歌山市）＝医師の肩書き専用。サイドビジネスで
  変な色をつけない。**客は"非地元"（東京/大阪/名古屋）か、地理に縛られない
  コミュニティ（士業・オンライン）から取る**。地元クリニックのサイト制作で失敗
  すると医師の評判に傷がつくため、地元案件は避ける。
- **統一ルール**：客は"非地元"。入り口は"自分が属する部族"。
  部族① 士業（行政書士フック）／部族② 遠方クリニック（医師の信頼）。

### 具体設計（仮・ニッチのみ要確定）

**ニッチは2つの部族から選ぶ（どちらも"非地元"で成立）：**

**部族① 士業（行政書士フック）← いまの制約に一番フィット**

| 項目 | 中身 |
|------|------|
| **誰に** | 行政書士・税理士・司法書士・弁護士（全国・オンライン） |
| なぜ強い | 同業として中に入れる＝コールド営業の何倍も効く信頼。士業は金があって集客が下手＝理想の高単価B2B。全国/オンライン完結で**地元の医師アイデンティティを汚さない**。本人は士業隣接サイトを作った実績あり |
| 行政書士の役割 | キャリアではなく**入場券＝営業フック**。「行政書士で食べたい」を看板に会へ入り、同業の集客/追客自動化/サイトを受注する |

**部族② 遠方クリニック（医師の信頼）— 地元以外限定**

| 項目 | 中身 |
|------|------|
| **誰に** | 東京/大阪/名古屋等のクリニック・歯科・治療院（※地元・和歌山は不可） |
| なぜ強い | 本人が医療の中の人＝信頼と単価。Phase 2の医療人脈・土地勘と補強。医療広告ガイドライン知識が参入障壁 |
| 注意 | 地元案件は医師の評判リスクで不可。遠方ゆえ温かい人脈は使いにくく、アウトバウンド難度は上がる |

**共通：何を売るか**

| 項目 | 中身 |
|------|------|
| **入口** | LP・サイト改修 ＋ 問い合わせ/予約動線（単発・実績作り） |
| **本命** | 月額顧問：問い合わせ自動返信・追客自動化・進捗/抜け漏れ管理・リマインド・口コミ依頼自動化・AI一次対応・更新/SEO（士業なら受任率↑、クリニックなら集患↑） |
| **訴求** | 「問い合わせ→受注の率が20〜40%上がる仕組みを回し続ける」=成果に紐づくから月額が剥がれにくい |
| **いくら** | 入口 ¥30万前後／月額顧問 ¥5万アンカー。顧問5社＝月¥25万＋入口で **月30〜50万＝家計の地面** |
| **最初の1社** | アウトバウンド（SEO待ちはしない）。属する部族に*具体的な穴*を指摘→実績→紹介。例）士業「問い合わせ放置されてませんか→自動返信＋追客で受任率↑」／遠方クリニック「予約電話だけ→LINE自動化で取りこぼし減」 |

### 行政書士フックの3注意（目を開けて入る）

1. **合格 ≠ 会に入れる**。"行政書士です"と名乗り会に入るには**登録（事務所＋入会金
   20万前後＋月会費）**が要る。フック獲得にコストと月額が発生。※和歌山県行政書士会の
   正確な額は要確認。登録せず"合格者"として勉強会/SNSで接点を作る軽い入り方もある
   （アクセスの深さとコストのトレードオフ）。
2. **フックは遅い**（受かる→登録→関係構築→受注で半年〜1年超）。家計は今要るので、
   **near-termの速い現金チャネルを並行**（既存サイトを実績に、地元以外の知り合いの
   商売へ直接売る）。優雅な遅い計画で家計を餓死させない。
3. **本物にする**。小さく評判に敏感な士業界で「騙し」が漏れると逆に評判を傷つける。
   本当に登録して本当に同業の集客を助ける＝嘘がなく、紹介とリピートが回る。
   正直版の方が儲かるし安全。欲しいのは「同じ部族から入る」一点だけ。

## 医師免許の使い方：レーン選択

「医者」は一つの仕事ではなく、免許は**メニュー**。低WM負荷 × 高自由度の項目を選ぶ。

| 働き方 | WM負荷 | 場所・時間の自由 | 相性 |
|--------|--------|------------------|------|
| **嘱託産業医** | 低 | 高（1社 月1〜数回を複数掛け持ち） | ★本命。B2Bで一番お金を落とす |
| **健診・人間ドックバイト** | 極低 | 高（働く日を選ぶ・1日¥5〜10万・継続診療なし） | ★単発で稼げる。旅と両立 |
| ~~オンライン診療（自由診療）~~ | 低 | × 海外からは距離・在宅制限で実質不可 | 当面外す（国内拠点が要る） |
| **精神科・心療内科の外来 非常勤** | 中〜低 | 中 | ◎ 言語理解113が武器。PTで精神病院にいた時「こんな緩い所ない」と実感済み |
| **寝当直・施設当直**（救急当直は除く） | 低 | 中（夜だけ・¥3〜10万） | ◎ 忙しい救急当直は選ばない |
| 救急 / 外科 / 産婦人科 / 急性期病棟 | **高** | 低 | ❌ 避ける（WMの谷を最も深く突く） |

**結論**：クリニックを開く必要も、毎日同じ時間に出勤する必要もない。
フリーランス非常勤医として低WM・高自由メニューをつまみ食い ＝
「ある程度のお金 ＋ 場所と時間の自由 ＋ 低ストレス」＝ 旅する人生そのもの。

> ⚠ 「自分のクリニックを開く」は罠。毎日開けねばならず、非常勤医を雇って回るまで
> 何年もかかり、旅の人生が消える。**開業はしない。**
