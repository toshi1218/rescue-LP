## 🔴 P0 — 出力が壊れているバグ（最適化ではなく故障）

### P0-1. `/en/psa-late-registration/` の meta description が消滅 → ✅ 修正（別PR #331）

生成HTMLの実物:

```html
<meta name="description" content="PSA says ">
```

原因: `scripts/prerender.ts` の `updateHead()` が title/description を `content="..."` に
**エスケープせず**流し込んでいる（`prerender.ts:1717` 近辺）。この description は
`PSA says "no record found"...` と二重引用符を含むため、属性が途中で切れて本文が全欠落。

同じ根本原因で、EN title 13本の生 `&`（`Marriage & Visa` 等＝W3C不正）も未エスケープ。

**修正案（`scripts/prerender.ts`）** — Level2ガード対象ファイル、要明示許可:

```ts
// escapeRegExp の直後に追加
function escapeHtml(value: string): string {
  return value
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;');
}
```

`updateHead()` 内で title / description を挿入している6箇所（`<title>`・`meta description`・
`og:title`・`og:description`・`twitter:title`・`twitter:description`）で
`route.title` → `escapeHtml(route.title)`、`route.description` → `escapeHtml(route.description)` に置換。

**実測波及**: 意味が変わるのは `/en/psa-late-registration/` の1ページのみ。
他は `&` → `&amp;`（SERP・ブラウザ表示は同一）の正規化のみ。構造ファイル（hreflang/canonical/sitemap）は無変更。

### P0-2. JA/KO ページの OG画像がハイドレーション後に 404 → ✅ 修正（別PR #331）

`lib/useMeta.ts:13-14` が `og:image` / `twitter:image` を `/og-image-ja.png`・`/og-image-ko.png` に
書き換えるが、**このファイルは `public/` に存在しない**（あるのは `og-image.png` / `.svg` / `.webp`）。
静的HTMLは正しく `og-image.png` を出しているのに、JSが壊れたパスで上書きする。
→ JSを実行する SNS/チャットのスクレイパーで JA/KO のOGサムネイルが割れる。

**修正案（`lib/useMeta.ts`）** — Level2ガード対象ファイル、要明示許可:

```ts
// 実在ファイルに合わせる（最小修正）
const JA_OG_IMAGE = `${BASE}/og-image.png`;
const KO_OG_IMAGE = `${BASE}/og-image.png`;
```

（将来 JA/KO 専用OG画像を作るなら `public/og-image-ja.png`・`og-image-ko.png` を配置して元の参照に戻す。）

### P0-3. 3ページに `<h1>` が皆無 → ✅ 本監査で修正済み

`/en/psa-ecertificate-abroad/`・`/ja/psa-ecertificate-nihon/`・`/ko/psa-ecertificate-hanguk/` の3ページだけ
`HeroBanner`（h1を出す）を使わず `<h2>` から始まり、H1が存在しなかった。
各ページ先頭に `<header><h1>…</h1><p>…</p></header>` を追加（ガード対象外・PC/スマホ実機確認済み）。
