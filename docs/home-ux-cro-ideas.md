## 0. 波及範囲マップ（最重要・実装前に必読）

トップが使うコンポーネントの「触ったとき何ページに波及するか」を実測した結果。
**サイト全体波及（コミット量シグナル）を避けるため、変更はできるだけ波及の狭いものに限定する。**

| 対象 | 波及範囲 | 凍結期の可否 |
|------|---------|------------|
| `HomeJa.tsx` 内の直書きJSX（ジャンプバー・紙原本通知） | **HomeJaのみ（1ページ）** | ✅ 最も安全 |
| `ServicePacks` | **HomeJaのみ（1ページ）** | ✅ 安全 |
| `Hero` / `PainPoints` / `WhyUs` / `SocialProof` / `CaseStudies` / `DiyRisks` / `QuickFacts` / `FAQ` | **HomeJa + HomeEn（2ページ）** | ⚠️ 日英トップ両方に出る。許容範囲だが要意識 |

## 1. ファーストビュー（最優先・離脱率に直結）

### 課題（実画面・コード確認済み）
- **CTAが3つ縦積みで全部強い色**（金=無料相談 / 紺=料金を見る / 緑=LINE）。
  3つとも目立つため視線が分散し、「どれを押せばいいか」の判断コストが上がる（決定麻痺）。
  モバイルでは3つの全幅ボタンがファーストビューを占有し、本文が押し下げられる。
- **JA Heroには信頼の視覚要素がない**。EN Heroには右側に「書類カード＋実績バー（500+ Cases / 4.8★ / 24h）」があるのに、
  JAは写真＋テキストのみ。日本人ユーザーの第一印象が相対的に弱い。

### 改善案
1. **CTA階層を明確化**（推奨・効果大/コスト小）
   - 主CTA「無料相談する」を1つだけ強い金色で大きく。
   - 「料金を見る」はテキストリンク or アウトライン（枠線）ボタンに格下げ。
   - LINEは緑のまま残すが、サイズを一段下げる or アイコンボタン化。
   - → 視線を1点に集約し、相談CTAのクリック率を上げる狙い。
   - **波及**: Hero JAブロックのみ（2ページだが分岐でJA限定可）／**CWV**: クラス変更のみ、CLSリスク極小。
2. **JA Heroにも実績バーを追加**（効果中/コスト小）
   - EN Heroの「500+ / 4.8★ / 24h」相当の数値バーをJA側にも。写真上に半透明カードで。
   - 既にレビュー4.8/47件の表示はあるので、それを数値バー化して視認性UP。
   - **波及**: Hero JAブロックのみ／**CWV**: 要素追加でCLS微増の可能性 → `min-h` で高さ予約すれば回避可。
3. **H1直下の価格ヒントを上に**（効果小/コスト小）
   - 現在「国際結婚準備パック ¥99,800〜」がCTAより下・薄色。予算ミスマッチ層の早期離脱を促す意味で、もう少し見やすく。

## 2. 紙原本通知セクション（HomeJa直書き・1ページ波及）

### 課題
- ファーストビュー直後に**赤基調の大きな警告ブロック**。情報としては重要だが、
  「2026年3月のPSAデジタル化で電子文書が受理されない」という**ネガティブ情報が価値提案より先に来る**。
- 初見ユーザーには不安喚起が先行し、サービス便益（渡航不要・日本語完結）が後回しになっている。

### 改善案
1. **順序の検討**: 価値提案（ServicePacks/WhyUs）を先に見せ、紙原本通知はその直後に置く案。
   ただし「紙原本対応＝差別化要素」でもあるので、**完全に下げず、トーンをポジティブ化**（"当社は紙原本に対応可能" を主役に）するのが無難。
2. **デフォルト折りたたみは維持**（既に `noticeExpanded` 実装済み）。初期表示の高さをさらに圧縮。
- **波及**: HomeJaのみ／**CWV**: アコーディオン初期折りたたみで初期DOM軽量化 → むしろプラス。

## 3. ページ全体の構成・長さ

### 課題
- セクションが9連続（ServicePacks→PainPoints→WhyUs→SocialProof→CaseStudies→DiyRisks→GuideLinks→QuickFacts→FAQ）と長い。
- 中盤に**CTAの再出現が乏しい**。長いページの途中で「相談したい」と思った人の受け皿が少ない。

### 改善案
1. **中盤CTA挿入**（効果中/コスト小）: WhyUs後・CaseStudies後あたりに軽いCTA（"無料相談する"）を1つ挿入。
   - **波及**: HomeJaに直書きすれば1ページのみ。
2. **セクション順の最適化検討**: SocialProof（実績）とCaseStudies（事例）を前方に寄せ、信頼を早期に積む。
   - **波及**: HomeJa.tsxのJSX並び替えのみ（コンポーネント本体は不変）→ 1ページ。CLSリスクなし。
